# 小数マスター PARK

小学3年生の算数「小数のしくみ」を中心に、分数・小数・図・数直線を行き来しながら数の大きさをつかむ、ゲームパーク型のWeb教材です。

## 公開ページ

- 公開版（main）：https://tt-sensei.github.io/syousuumaster/
- 開発ブランチ：feature/syousuumaster-park

このブランチは公開版を置き換えずに開発・確認するためのものです。GitHub Pagesの公開先はmain側の設定に従います。

## 学習の中心

学びの地図で次の第3学年の項目を中心にしています。

- `jp.elem.math.decimals-tenths` — 小数の意味（十分の一の位）
- `jp.elem.math.decimal-fraction-tenths` — 0.1 と 1/10 の関係
- `jp.elem.math.decimal-fraction-numberline` — 小数・分数を数直線上で比べる（第3学年で扱う十分の一の範囲）

中心となる見方は「1を10こに分けた1こ分が 0.1 であり、1/10 と同じ大きさ」ということです。百分の一、小数の加減乗除など、上学年で扱う内容は第3学年の本編に入れていません。

## アトラクション

| エリア | 学ぶこと・遊び方 |
| --- | --- |
| 分数小数マッチ | 1/10 と 0.1、3/10 と 0.3 など、同じ大きさのカードをそろえる |
| 数直線レース | 0から1までを10等分した数直線で小数の場所を見つける |
| 小数ビルダー | 0.1ブロックを増減し、目標の小数を組み立てる |
| くらべっこアリーナ | 十分の一のいくつ分かを、図で比べる |
| 小数ミックスチャレンジ | 学んだ見方を組み合わせて挑戦する |
| 0.1モンスター | 既存の0.1が何こ分かの入力練習 |
| ジュース屋さん | 既存の L ⇔ dL の双方向換算 |
| ものさし探偵 | 既存の cm ⇔ mm の双方向換算 |

既存3モードは従来の単位換算・数値入力の学習体験を残し、PARKの中から選べるようにしています。ジュース屋さんとものさし探偵は第2学年の量の学習との接続・おさらいとして区別しています。

## 学習サイクル

- 問題は1回の挑戦の中で重複しないように出題。数直線の目盛りを読む問題、分数の目盛り、「あといくつで1になるか」、小数→分数の変換、「小さいのはどちら」など、複数の見方の問題を用意
- 正解で星と連続正解数を記録
- 間違えた内容を端末内に保存
- ホームの「弱点特訓」で同じ学習技能の別問題に挑戦
- 特訓で正解できた記録は解消
- 各エリアの全問正解でマスター進捗とエリア別バッジを獲得
- 8エリアすべてをマスターするとパークめぐりバッジを獲得

答えを見た問題は正解数・マスター達成に含めません。

## 共通資産

- edu-components：StorageManager、ProgressManager、BadgeManager、ComboManager
- edu-effects：基本UI、正解・不正解・バッジ獲得演出
- sounds-recipe-：正解、ヒント、開始、バッジなどの効果音
- edu-assets：算数・共通バッジのWebP画像
- navi-character-：ファンタジー集合画像、ナビキャラ、ナビアン画像

補助資産が読み込めなくても、学習本体が止まらないようにしています。画像URLは各資産リポジトリの実在ファイルを確認したものを使います。

## 技術

- HTML / CSS / Vanilla JavaScript
- ビルド不要
- 外部API、APIキー、外部DBなし
- 進捗・星・バッジ・苦手記録はStorageManagerのnamespace `syousuumaster-park` で端末内に保存
- 共通資産はGitHub Pagesの公開URLから読み込み（画像・演出・効果音・共通ロジック）

## ファイル

- `index.html` — 画面の骨格
- `styles.css` — パーク・学習画面のスタイル
- `app.js` — 学習進行、問題生成、記録、共通資産接続
- `activities.js` — アトラクション・バッジの定義

新しいエリアを追加する場合は、まず `activities.js` にアトラクション定義を追加し、問題形式を `app.js` に実装します。問題データと判定の責任を表示・演出から分離する方針です。
