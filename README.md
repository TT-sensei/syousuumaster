# 小数マスター

小数の表し方と単位換算を練習できるWeb教材です。3つのモードすべてが「どっち向き」にも出題される（双方向）作りで、正解すると「ほし」が集まり、ランクが上がっていきます。

## 公開ページ

[GitHub Pagesで開く](https://tt-sensei.github.io/syousuumaster/)

## モード

- 🍹 ジュース屋さん：L ⇔ dL の単位換算
- 📏 ものさし探偵：cm ⇔ mm の単位換算
- 👾 0.1モンスター：こすう ⇔ 小数（「0.1が何こ分」で小数をとらえる）

どのモードも、換算の向きが両方向ランダムに出ます。

## ランク

正解して「ほし」を集めると、見習いからランクアップしていきます（小数名人、小数大王など）。

## 対象

小学校2〜3年生中心。小数の仕組みは3年生の単元で、L⇔dL・cm⇔mmの単位換算は2年生の量の学習ともつながります。

## 技術メモ

- `index.html` の単一ファイルで動作し、ビルド不要
- 外部APIなどの外部通信なし（ブラウザだけで動作）
